## Scope and limits

These were actual isolated agent exercises in this environment, not interactive Claude Code,
Cursor, Cline or other application sessions. Native filesystem installation checks are reported
separately from behavioral exercises. Automatic skill selection was not exercised: each agent
received its named skill. The optional paid LLM instruction audit was not run.

All 24 original skills received a content review and refactor; four new skills were added.
Three behavioral cases do not establish that all 28 workflows behave correctly in every host.
Future changes should add targeted fixtures for their own failure modes and record actual
host/model identifiers when available.

Exact skill-file hashes were not retained at execution time; these exercises preceded the
final formatting pass. Treat the observations as bounded evidence for this refactor, not a
hash-pinned benchmark. Future run records should capture those identifiers before execution.
